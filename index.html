Research & Engineering

Campus-Mind

Intelligent Campus Learning and Life Assistant

Jan 2026 — Present
  • LLM
  • RAG
  • Neo4j
  • React
  • Python

Campus-Mind is an intelligent assistant for the Weihai Campus of Beijing Jiaotong University. It brings together campus information Q&A, personalized academic analysis, English-learning support, project workspaces, and long-term memory in one system.

Status

Internal beta testing is planned for summer 2026, with campus deployment targeted for September 2026.

Selected contributions

  1. Designed the retrieval-augmented generation pipeline and Q&A chain.
  2. Built domain knowledge bases from textbooks, course materials, campus policies, and university web content.
  3. Integrated Neo4j and GraphRAG to create a searchable, extensible, and explainable campus knowledge network.
  4. Developed preprocessing, segmentation, indexing, retrieval, and reranking workflows.
