Research & Engineering Project

Campus-Mind

Intelligent Campus Learning and Life Assistant

Jan 2026 — Present
  • LLM
  • RAG
  • Neo4j
  • React
  • Python

Campus-Mind is an intelligent assistant for the Weihai Campus of Beijing Jiaotong University. It brings together campus information Q&A, personalized academic analysis, English-learning support, project workspaces, and long-term memory in a unified system.

System Design

The system answers questions about study plans, academic records, course schedules, and campus life. It uses student profile data to analyze program requirements, academic progress, and course information, while maintaining independent context for different learning and project tasks.

My Contributions

  • Designed the retrieval-augmented generation pipeline and Q&A chain.
  • Built domain knowledge bases from textbooks, course materials, campus policies, and university web content.
  • Integrated Neo4j and GraphRAG to create a searchable, extensible, and explainable campus knowledge network.
  • Developed data preprocessing, segmentation, indexing, retrieval, and reranking workflows.
Status

Internal beta testing is planned for summer 2026, with campus deployment targeted for September 2026.
